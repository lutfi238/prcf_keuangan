## 📋 How to Use

### Exporting from Bank Book
1. Go to **Buku Bank** page
2. Expand your project → year → month
3. Click **Export to Excel** (green button)
4. File downloads automatically
5. Open file
6. **Ready to print!** ✅

### Exporting from Accounts Receivable
1. Go to **Buku Piutang** page
2. Expand your project → year → month
3. Click **Export to Excel** (green button)
4. File downloads automatically
5. Open file
6. **Ready to print!** ✅

## 🖨️ Printing Instructions

### Method 1: Quick Print
1. Open the exported Excel file
2. Press **Ctrl+P** (Windows) or **Cmd+P** (Mac)
3. Click **Print**
4. Done!

### Method 2: Print with Preview
1. Open the exported Excel file
2. Go to **File** → **Print**
3. Review print preview (should look perfect!)
4. Click **Print**
5. Done!

### Method 3: Save as PDF
1. Open the exported Excel file
2. Go to **File** → **Print**
3. Select **Microsoft Print to PDF** as printer
4. Click **Print**
5. Choose save location
6. PDF created - perfect for emailing or archiving!

## ❓ Troubleshooting

### Problem: Content Still Looks Cut Off

**Solution 1**: Check Excel Version
- Requires Microsoft Excel 2007 or later
- Or LibreOffice Calc / Google Sheets

**Solution 2**: Check Print Preview
1. File → Print
2. Look at preview on the right
3. Should show all content
4. If not, check scaling settings

**Solution 3**: Manual Override (if needed)
1. Go to **Page Layout** tab
2. Click **Orientation** → Select **Portrait**
3. Click **Margins** → Select **Normal**
4. Click **Width** dropdown → Select **1 page**

### Problem: Printing to Wrong Paper Size

**Solution**:
1. File → Print
2. Click **Printer Properties**
3. Select **Letter** or **A4** paper size
4. Click OK

### Problem: Text Too Small

**Solution**:
1. This is normal - content is scaled to fit one page
2. For larger text, print on larger paper (Legal size)
3. Or adjust scaling: Page Layout → Scale to Fit → 100%

## 📞 Need Help?

**Common Questions**:

**Q: Can I change to landscape?**  
A: Yes! Page Layout → Orientation → Landscape (but portrait is recommended)

**Q: Can I print on A4 paper?**  
A: Yes! Excel auto-adjusts. Just select A4 in printer settings.

**Q: How many pages will it print?**  
A: Width: Always 1 page. Height: Depends on number of transactions.

**Q: Can I print specific rows?**  
A: Yes! Select rows → File → Print → Print Selection

**Q: What if I want bigger text?**  
A: Page Layout → Scale to Fit → Increase percentage (may cause cutoff)
