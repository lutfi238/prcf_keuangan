# Bank Book Excel Export - Quick Reference Card

## 🚀 Quick Start (30 seconds)

1. **Go to** Buku Bank page
2. **Expand** your project → year → month
3. **Click** green "Export to Excel" button
4. **Done!** File downloads automatically

## ⚡ Tips & Tricks

### Tip 1: Multiple Exports
Click export on different periods to compare data side-by-side.

### Tip 2: Open in New Tab
Export opens in new tab - your current page stays intact!

### Tip 3: Excel Warning
If Excel shows XML warning → Click "Yes" (file is safe).

### Tip 4: Number Format
Numbers auto-format with commas: 1,000,000.00

### Tip 5: Print Ready
Excel file is pre-formatted for professional printing.

---

## ❓ Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| Button not visible | Refresh page, check you're Finance Manager |
| Download blocked | Allow popups for localhost |
| Excel shows warning | Normal for XML files - click "Yes" |
| Wrong data | Check you exported correct period |
| File won't open | Use Excel 2007+ or LibreOffice |
