## 📌 OVERVIEW

Sistem Budget Management ini memungkinkan:
1. **FM (Finance Manager)** mengelola budget per Exp Code dan Place Code yang dipisah per desa
2. **PM (Project Manager)** menginput budget yang diperlukan saat membuat proposal
3. **FM** melihat informasi budget availability saat review proposal
4. **Auto-Disbursement** otomatis ke buku bank, buku piutang, dan unliquidated setelah FM approve

### 2. Tabel Baru: `project_code_budgets` (Budget per Exp & Place Code per Desa)

⚠️ **IMPORTANT**: `place_code` adalah kolom biasa (bukan GENERATED), akan di-populate oleh PHP.

```sql
CREATE TABLE IF NOT EXISTS `project_code_budgets` (
  `id_budget` INT PRIMARY KEY AUTO_INCREMENT,
  `kode_proyek` VARCHAR(50) NOT NULL,
  `id_village` INT NOT NULL,
  `exp_code` VARCHAR(20) NOT NULL COMMENT 'Expense code, misal: 10101, 20208',
  `place_code` VARCHAR(50) NOT NULL COMMENT 'Format: [exp_code]-[village_abbr]-01, generated by PHP',
  `budget_usd` DECIMAL(15,2) DEFAULT 0.00 COMMENT 'Budget dalam USD',
  `budget_idr` DECIMAL(15,2) DEFAULT 0.00 COMMENT 'Budget dalam IDR',
  `used_usd` DECIMAL(15,2) DEFAULT 0.00 COMMENT 'Budget terpakai (USD)',
  `used_idr` DECIMAL(15,2) DEFAULT 0.00 COMMENT 'Budget terpakai (IDR)',
  `remaining_usd` DECIMAL(15,2) GENERATED ALWAYS AS (`budget_usd` - `used_usd`) STORED,
  `remaining_idr` DECIMAL(15,2) GENERATED ALWAYS AS (`budget_idr` - `used_idr`) STORED,
  `exrate` DECIMAL(10,4) DEFAULT 1.0000 COMMENT 'Exchange rate USD to IDR',
  `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  `updated_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (`kode_proyek`) REFERENCES `proyek`(`kode_proyek`) ON DELETE CASCADE,
  FOREIGN KEY (`id_village`) REFERENCES `villages`(`id_village`) ON DELETE RESTRICT,
  UNIQUE KEY `unique_budget_per_village` (`kode_proyek`, `id_village`, `exp_code`),
  INDEX `idx_place_code` (`place_code`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='Budget allocation per exp code per village';
```

**Place Code Generation Logic (PHP)**:
```php
// Get village abbreviation
$stmt = $conn->prepare("SELECT village_abbr FROM villages WHERE id_village = ?");
$stmt->bind_param("i", $id_village);
$stmt->execute();
$village = $stmt->get_result()->fetch_assoc();

// Generate place_code: [exp_code]-[village_abbr]-01
$place_code = $exp_code . '-' . $village['village_abbr'] . '-01';
// Example: 10101-NJ-01
```

```javascript
function updatePlaceCode(element, rowIndex) {
  let villageAbbr = $('#budget_details_' + rowIndex + '_id_village option:selected').data('abbr');
  let expCode = $('#budget_details_' + rowIndex + '_exp_code').val();
  
  if (villageAbbr && expCode) {
    let placeCode = expCode + '-' + villageAbbr + '-01';
    $('#budget_details_' + rowIndex + '_place_code').val(placeCode);
  }
}

function calculateIDR(inputUSD, rowIndex) {
  let usd = parseFloat(inputUSD.value) || 0;
  let exrate = parseFloat($('#exrate').val()) || 1;
  let idr = usd * exrate;
  $('#budget_details_' + rowIndex + '_requested_idr').val(idr.toFixed(2));
}

function calculateUSD(inputIDR, rowIndex) {
  let idr = parseFloat(inputIDR.value) || 0;
  let exrate = parseFloat($('#exrate').val()) || 1;
  let usd = idr / exrate;
  $('#budget_details_' + rowIndex + '_requested_usd').val(usd.toFixed(2));
}
```

## 💰 E. FITUR 4: AUTO-DISBURSEMENT SETELAH FM APPROVE

⚠️ **CRITICAL**: Process ini harus dibungkus dalam TRANSACTION untuk memastikan data consistency.

**Update File**: `pages/proposals/review_proposal_fm.php` (POST Handler)

### Trigger: 
Ketika FM klik tombol **"Setujui Proposal (Pencairan Dana)"**

### Proses Otomatis (TRANSACTION-WRAPPED):

```php
<?php
if ($_SERVER['REQUEST_METHOD'] === 'POST' && isset($_POST['approve'])) {
    $proposal_id = $_POST['proposal_id'];
    $exrate_disbursement = floatval($_POST['exrate_disbursement']);
    
    if ($exrate_disbursement <= 0) {
        die('Exchange rate tidak valid!');
    }
    
    $conn->begin_transaction();
    
    try {
        // 1. Get Proposal & Budget Details
        $stmt = $conn->prepare("SELECT p.*, u.id_user as pm_id, u.nama as pm_name, u.email as pm_email 
                                FROM proposal p 
                                LEFT JOIN user u ON p.pemohon = u.nama 
                                WHERE p.id_proposal = ?");
        $stmt->bind_param("i", $proposal_id);
        $stmt->execute();
        $proposal = $stmt->get_result()->fetch_assoc();
        
        $stmt = $conn->prepare("SELECT pbd.*, v.village_name, v.village_abbr 
                                FROM proposal_budget_details pbd 
                                LEFT JOIN villages v ON pbd.id_village = v.id_village 
                                WHERE pbd.id_proposal = ?");
        $stmt->bind_param("i", $proposal_id);
        $stmt->execute();
        $budget_details = $stmt->get_result()->fetch_all(MYSQLI_ASSOC);
        
        // 2. Get or Create Piutang Header
        $stmt = $conn->prepare("SELECT id_piutang FROM buku_piutang_header 
                                WHERE account_name = ? AND kode_proyek = ?");
        $stmt->bind_param("ss", $proposal['pm_name'], $proposal['kode_proyek']);
        $stmt->execute();
        $piutang_result = $stmt->get_result();
        
        if ($piutang_result->num_rows == 0) {
            $stmt = $conn->prepare("INSERT INTO buku_piutang_header 
                (kode_proyek, account_name, periode_mulai, created_by, status) 
                VALUES (?, ?, NOW(), ?, 'draft')");
            $stmt->bind_param("ssi", $proposal['kode_proyek'], $proposal['pm_name'], $user_id);
            $stmt->execute();
            $id_piutang = $conn->insert_id;
        } else {
            $id_piutang = $piutang_result->fetch_assoc()['id_piutang'];
        }
        
        // 3. Loop Budget Details
        foreach ($budget_details as $detail) {
            // Recalculate amounts
            $amount_usd = $detail['requested_usd'];
            $amount_idr = $amount_usd * $exrate_disbursement;
            
            if ($proposal['currency'] === 'IDR') {
                $amount_idr = $detail['requested_idr'];
                $amount_usd = $amount_idr / $exrate_disbursement;
            }
            
            $reff = 'PROP-' . str_pad($proposal_id, 6, '0', STR_PAD_LEFT);
            $activity = 'Pencairan Dana: ' . $proposal['judul_proposal'];
            $cost_desc = $detail['description'] ?? $activity;
            
            // ===== A. INSERT BUKU BANK (Get ID for voucher) =====
            $stmt = $conn->prepare("INSERT INTO buku_bank 
                (kode_projek, date, reff, activity, cost_desc, recipient, 
                 p_code, exp_code, credit_idr, credit_usd, exrate, cost_curr) 
                VALUES (?, NOW(), ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)");
            
            $stmt->bind_param("sssssssddds", 
                $proposal['kode_proyek'],
                $reff,
                $activity,
                $cost_desc,
                $proposal['pm_name'],
                $detail['place_code'],
                $detail['exp_code'],
                $amount_idr,
                $amount_usd,
                $exrate_disbursement,
                $proposal['currency']
            );
            $stmt->execute();
            
            // Get inserted buku_bank ID
            $id_bank = $conn->insert_id;
            
            // ===== GENERATE VOUCHER NUMBER FOR AUDIT TRAIL =====
            // Format: BB-[id_bank]-PROP-[id_proposal]
            // Example: BB-001234-PROP-000045
            $voucher_no = 'BB-' . str_pad($id_bank, 6, '0', STR_PAD_LEFT) . 
                          '-PROP-' . str_pad($proposal_id, 6, '0', STR_PAD_LEFT);
            
            // Update buku_bank with standardized reff
            $conn->query("UPDATE buku_bank SET reff = '$voucher_no' WHERE id_bank = $id_bank");
            
            // ===== B. INSERT BUKU PIUTANG DETAIL =====
            $stmt = $conn->prepare("INSERT INTO buku_piutang_detail 
                (id_piutang, tgl_trx, reff, description, recipient, p_code, exp_code, 
                 debit_idr, debit_usd, exrate) 
                VALUES (?, NOW(), ?, ?, ?, ?, ?, ?, ?, ?)");
            
            $stmt->bind_param("issssssdd", 
                $id_piutang,
                $voucher_no,
                $cost_desc,
                $proposal['pm_name'],
                $detail['place_code'],
                $detail['exp_code'],
                $amount_idr,
                $amount_usd,
                $exrate_disbursement
            );
            $stmt->execute();
            
            // ===== C. INSERT BUKU PIUTANG UNLIQUIDATED (CRITICAL!) =====
            $description_unl = 'Advance: ' . $proposal['judul_proposal'] . 
                              ' | Place: ' . $detail['place_code'] . 
                              ' | Bank ID: ' . $id_bank;
            
            $stmt = $conn->prepare("INSERT INTO buku_piutang_unliquidated 
                (id_piutang, tgl, voucher_no, name, description, nilai_idr, nilai_usd, status) 
                VALUES (?, NOW(), ?, ?, ?, ?, ?, 'pending')");
            
            $stmt->bind_param("isssdd", 
                $id_piutang,
                $voucher_no,  // ✅ Enhanced: Bank transaction ID for audit trail
                $proposal['pm_name'],
                $description_unl,
                $amount_idr,
                $amount_usd
            );
            $stmt->execute();
            
            // ===== D. UPDATE BUDGET USAGE =====
            $stmt = $conn->prepare("UPDATE project_code_budgets 
                SET used_usd = used_usd + ?, 
                    used_idr = used_idr + ? 
                WHERE kode_proyek = ? 
                AND place_code = ?");
            
            $stmt->bind_param("ddss", 
                $amount_usd, 
                $amount_idr, 
                $proposal['kode_proyek'], 
                $detail['place_code']
            );
            $stmt->execute();
        }
        
        // 4. Update Proposal Status
        $stmt = $conn->prepare("UPDATE proposal 
            SET status = 'approved_fm', 
                approved_by_fm = ?, 
                fm_approval_date = NOW() 
            WHERE id_proposal = ?");
        $stmt->bind_param("ii", $user_id, $proposal_id);
        $stmt->execute();
        
        // 5. COMMIT
        $conn->commit();
        
        // 6. Notification
        send_notification_email(
            $proposal['pm_email'],
            'Proposal Disetujui - Dana Telah Dicairkan',
            'Proposal "' . $proposal['judul_proposal'] . '" telah disetujui. ' .
            'Total dana yang dicairkan: $' . number_format($proposal['total_budget_usd'], 2) . '. ' .
            'Silakan submit LPJ setelah kegiatan selesai.'
        );
        
        header('Location: review_proposal_fm.php?id=' . $proposal_id . '&success=disbursed');
        exit();
        
    } catch (Exception $e) {
        $conn->rollback();
        $error = 'Gagal melakukan pencairan dana: ' . $e->getMessage();
        error_log('Auto-Disbursement Error: ' . $e->getMessage());
    }
}
?>
```

```

    ↓
[Validate Exrate]
    ↓
[BEGIN TRANSACTION]
    ↓

    ↓

    ↓
[COMMIT TRANSACTION]
    ↓
[Send Email Notification]
    ↓
[Redirect dengan Success Message]
```

## 🎫 VOUCHER NUMBER FORMAT - AUDIT TRAIL

### Format Standard:
```
BB-[ID_BANK]-PROP-[ID_PROPOSAL]
```

### Contoh:
- `BB-000123-PROP-000045` 
  - Bank Transaction ID: 123
  - Proposal ID: 45

### Benefit untuk Audit:
1. ✅ Auditor bisa langsung cari transaksi di Buku Bank menggunakan ID: `BB-000123`
2. ✅ Bisa trace back ke proposal source: `PROP-000045`
3. ✅ Konsisten di 3 tabel: `buku_bank`, `buku_piutang_detail`, `buku_piutang_unliquidated`

### Cross-Reference Flow:
```
Buku Piutang Unliquidated (voucher_no: BB-000123-PROP-000045)
          ↓ (search by voucher_no)
Buku Bank (id_bank: 123, reff: BB-000123-PROP-000045)
          ↓ (search by reff)
Buku Piutang Detail (reff: BB-000123-PROP-000045)
          ↓ (search by PROP-000045)
Proposal (id_proposal: 45)
```

## 🔧 J. TECHNICAL NOTES & CRITICAL FIXES

### ✅ Fix #1: Generated Column Issue

**Problem**: MySQL does not support subqueries or references to other tables in GENERATED columns.

**❌ Wrong Approach**:
```sql
place_code VARCHAR(50) NOT NULL GENERATED ALWAYS AS (
  CONCAT(exp_code, '-', (SELECT village_abbr FROM villages WHERE id_village = project_code_budgets.id_village), '-01')
) STORED
```

**✅ Correct Approach**:
```sql
-- Make place_code a regular column
place_code VARCHAR(50) NOT NULL COMMENT 'Generated by PHP: [exp_code]-[village_abbr]-01'

-- PHP generates the value during INSERT
$place_code = $exp_code . '-' . $village_abbr . '-01';
```

### ✅ Fix #2: Voucher Number Enhancement for Audit Trail

**Problem**: Original plan used only `PROPOSAL-[id]` as voucher number, making it hard to trace back to bank transactions.

**❌ Before**:
```php
$voucher_no = 'PROPOSAL-' . $proposal_id;
```

**✅ After**:
```php
// Insert buku_bank first to get id_bank
$stmt->execute();
$id_bank = $conn->insert_id;

// Generate voucher with bank transaction ID
$voucher_no = 'BB-' . str_pad($id_bank, 6, '0', STR_PAD_LEFT) . 
              '-PROP-' . str_pad($proposal_id, 6, '0', STR_PAD_LEFT);

// Update buku_bank.reff for consistency
$conn->query("UPDATE buku_bank SET reff = '$voucher_no' WHERE id_bank = $id_bank");
```

**Benefits**:
- Direct cross-reference between unliquidated → buku_bank
- Audit trail: voucher_no contains both bank ID and proposal ID
- Consistent across all 3 tables
